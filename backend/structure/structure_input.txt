get_student_evidence_for_slot(sample, part_label, slot_ids) — hàm mọi heuristic
grader gọi để lấy bài làm sinh viên — trả về 1 dict evidence, KHÔNG phải
sample["student_answer"] nguyên bản. Field quan trọng nhất:

  evidence["student_answer"]   // str — nguyên văn bài làm (ghép nhiều dòng
                                // nếu slot có nhiều lines, nối bằng "\n").
                                // Tên field là "student_answer", KHÔNG phải
                                // "text" (đổi tên để tránh trùng nghĩa với các
                                // key "text" khác trong codebase — line/token/
                                // cell object ở sample["student_answer"]["lines"/
                                // "tables"] là schema hoàn toàn khác, vẫn giữ
                                // key "text" riêng của chúng).
                                // KHÔNG bị .strip() ở bước ghép cuối cùng —
                                // giữ nguyên khoảng trắng đầu/cuối của cả khối.
  evidence["tokens"]           // Luôn [] — xem ghi chú "tokens" ở trên.
  evidence["tables"]           // List các bảng liên quan tới slot này.
  evidence["visual_answers"]   // List các visual_answer liên quan.
  evidence["part_label"]       // part_label thực sự dùng để lọc.
  evidence["type"]             // "slot_matched" | "part_matched" | "blank" |
                                // "full_text" — nguồn evidence đến từ đâu (lọc
                                // theo slot_ids chính xác, fallback part_label,
                                // bài trống, hay fallback cuối cùng dump toàn

                                // slot_ids lẫn part_label đều không khớp gì).
  evidence["found"]            // bool — có tìm thấy evidence nào không.
  evidence["is_blank"]         // bool — chỉ có khi type="blank".
